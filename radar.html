カレンダー

読み込んだ本文から抽出・JST。日付を選ぶと詳細を表示します。

按文字自動分類；一年未寫明時會推算年份。海報內資料未作辨識，時間按日本時間（JST），請以原文為準。

暫時未有符合嘅內容

試吓其他分類、清除篩選，或者載入較舊貼文。

使用說明

貼上公開 X 帳戶，我哋透過開源 FxEmbed 公開服務取得最近貼文，按文字規則整理演出、MV 同售票資訊。無使用付費 X API 或付費 AI。

收藏同更新

追蹤名單、已讀記錄及最近結果只存在呢個瀏覽器。清除網站資料就會移除，其他裝置唔會同步。開啟帳戶或按更新時先查詢，唔會喺關閉網站後持續監察或發通知。

資料有幾新？

結果快取約 15 分鐘，上游亦可能有延遲；只包含已取得嘅貼文，唔保證完整歷史。來源失效時會清楚標示並顯示本機上次結果。

分類與日期

一篇貼文可以屬於多個分類。未註明年份會按發文日期推算，圖片內文字未辨識；活動同開售時間請核對原文。日曆匯出只包含日期，唔會猜測演出時間。

私隱與來源

唔需要登入 X，亦唔會索取你嘅密碼或 cookies。搜尋帳戶名稱會傳到本站 Cloudflare Worker 及 FxEmbed；圖片由 X 嘅媒體服務載入。Cloudflare／上游可能處理技術存取記錄。本站與 X 及藝人並無官方關係。
